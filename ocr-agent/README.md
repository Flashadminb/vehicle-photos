# Local OCR — โปรแกรมอ่านป้ายทะเบียนบนคอมของคุณ

อ่านป้ายด้วย **OpenCV.js** (หากรอบป้ายและดัดให้ตรง) และ **Tesseract.js** (อ่านตัวอักษรไทยและตัวเลข) โดยทำงานบนคอมของคุณทั้งหมด
- ไม่มีค่าใช้จ่าย
- ไม่ใช้โควต้าบริการคลาวด์
- รูปไม่ออกไปที่บริการภายนอก

## หลักการทำงาน
- โปรแกรมจะถามเซิร์ฟเวอร์ว่ามีป้ายรออ่านไหม (ทุก 30 วินาทีตอนว่าง) ถ้ามีจะดึงรูปมาอ่าน แล้วส่งผลกลับ
- **เปิดคอมเครื่องไหนก็ได้ที่ติดตั้งไว้ มีกี่เครื่องก็ได้**
- ระบบกันไม่ให้สองเครื่องอ่านป้ายเดียวกัน
- ปิดเครื่องกลางคัน เครื่องอื่นจะรับงานต่อภายใน 5 นาที
- ไม่ต้องเปิด port และไม่ต้องตั้งค่าเราเตอร์ เพราะคอมเป็นฝ่ายติดต่อเซิร์ฟเวอร์เอง

## ติดตั้ง (Windows)
1. ติดตั้ง Node.js เวอร์ชัน LTS จาก https://nodejs.org
2. แตกไฟล์ `ocr-agent.zip` ไว้ในโฟลเดอร์ เช่น `C:\ocr-agent`
3. ในแดชบอร์ด เมนู **อ่านป้ายทะเบียน (OCR)** → กด **+ เพิ่มเครื่อง** → กด **คัดลอก**
4. ดับเบิลคลิก `start-windows.bat` → ครั้งแรกโปรแกรมจะถามหา token ให้**คลิกขวาในหน้าต่างดำเพื่อวาง** แล้วกด Enter โปรแกรมจะสร้าง `config.json` ให้เอง
   - ครั้งแรกจะติดตั้งประมาณ 1–3 นาที
   - เมื่อขึ้นข้อความ "พร้อมทำงาน" แปลว่าใช้งานได้
5. (ไม่บังคับ) ให้โปรแกรมเปิดเองตอนเปิดคอม: กด Win+R → พิมพ์ `shell:startup` → วาง shortcut ของ `start-windows.bat`

ถ้าใช้ Mac หรือ Linux ให้รัน `./start-mac-linux.sh` แทน

## ทดสอบความแม่นยำกับรูปของคุณ (ไม่ต้องต่อเซิร์ฟเวอร์)
```
node test-image.mjs C:\รูปป้าย
```
- ถ้าตั้งชื่อไฟล์เป็นทะเบียนจริง (เช่น `กข1234.jpg`, `1กข2345.jpg`) โปรแกรมจะคำนวณเปอร์เซ็นต์ความแม่นให้
- ถ้าทดสอบทีละรูป ภาพที่ตัดมาอ่านจะถูกบันทึกไว้ในโฟลเดอร์ `debug/` ให้ดูได้ว่าโปรแกรมเห็นอะไร

## การตั้งค่าใน config.json
| ค่า | ความหมาย |
|---|---|
| `server` | URL ของระบบ |
| `token` | รหัสของเครื่องนี้ (สร้างในแดชบอร์ด แสดงครั้งเดียว) |
| `minConfidence` | ถ้าความมั่นใจต่ำกว่าค่านี้ (ค่าเริ่มต้น 0.6) จะไม่กรอกทะเบียน ให้คง "ไม่ระบุ" ไว้ให้ผู้ดูแลตรวจ |

## สเปกเครื่อง
- Windows 10/11, macOS หรือ Linux และ RAM 4 GB ขึ้นไป ไม่ต้องมีการ์ดจอ
- ใช้เวลาอ่านประมาณ 0.3–1.5 วินาทีต่อป้าย
- ใช้เน็ตประมาณ 1–2 MB ต่อป้าย (ดาวน์โหลดรูปต้นฉบับมาอ่าน)

## ข้อจำกัด
Tesseract ถูกออกแบบมาอ่านเอกสาร ไม่ใช่ป้ายรถ ผลทดสอบกับภาพจำลองได้ประมาณ 4 ใน 6
- พลาดบ่อยกับเลขนำหน้าที่ดูคล้ายตัวอักษร (3 ↔ ว) และพยัญชนะที่พบไม่บ่อย (ฌ, ญ, ฒ)
- ป้ายที่ถ่ายตรง ชัด และเต็มกรอบจะได้ผลดีที่สุด
- ผู้ดูแลแก้ทะเบียนในแดชบอร์ดได้เสมอ และการแก้มือจะไม่ถูก OCR ทับ
